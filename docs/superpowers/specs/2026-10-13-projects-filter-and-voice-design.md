# Projects section with filter + per-section voice narration

Date: 2026-10-13 · Status: approved in chat, awaiting spec review

## Goal

1. Make room for many personal projects (5+ and growing, each with Demo/GitHub
   links) without cluttering the page, by turning the existing "Dự án" section
   into one filterable, horizontally scrolling collection of work + personal
   projects.
2. Let visitors opt in to a voice-over (audio generated by the owner with Vbee)
   that plays the narration of whichever section they are on.

Non-goals: new sections or menu items, CMS, auto-generated audio, narration on
project detail pages.

## Part 1 — Projects section

### Data (`src/i18n/translations/{vi,en}.json` → `projects`)

Each item gains:

| Field | Type | Notes |
|---|---|---|
| `type` | `"work" \| "personal"` | required; existing 4 items become `"work"` |
| `links` | `{ demo?: string, github?: string }` | optional; shown as buttons |

Existing fields stay (`id, name, period, cardBackground, description, problem,
myRole, role, tasks, impact, tools, gallery`). Personal items need at least
`id, type, name, description, tools`; everything else optional.

New UI strings under `projects`:
`filters: { all, work, personal }`, `badges: { work, personal }`,
`actions.demo`, `actions.github`, `actions.prev`, `actions.next`.

"Has detail" = item has non-empty `tasks` or `gallery`. Only those items get
the **Chi tiết** button, the modal, a `/projects/<id>` page and a sitemap
entry (`getProjectIds` filters on this).

### Layout

- Header row: title on the left, filter chips on the right:
  `Tất cả (n) · Công ty (n) · Cá nhân (n)`, counts computed from data.
  Chips are buttons with `aria-pressed`; one active at a time; default "Tất cả".
- Card (same for all types): background image (`cardBackground`, else first
  gallery image), name, type badge, description clamped to 2 lines, up to 4
  tool tags (+N), action row: `Chi tiết` (if has detail), `Demo`, `GitHub`
  (if links). Demo/GitHub open in a new tab (`rel="noopener noreferrer"`).
  Problem / role / impact move off the card (still in modal + detail page).
- Desktop (≥768px): CSS grid, `grid-auto-flow: column`, 2 rows, fixed column
  width (~3 columns visible at 1440px), `overflow-x: auto`,
  `scroll-snap-type: x mandatory`. Prev/next buttons scroll by one visible
  page; dots show page count/position and are hidden when everything fits.
  Vertical wheel keeps changing fullpage sections (unchanged).
- Mobile (<768px): single column list, no horizontal scroll; chips stay.
- Filtering hides non-matching cards (`hidden`), resets scroll to the start
  and recomputes pages/dots. Language switch re-renders text as today.
- Order = order in JSON (personal projects first: they are the most recent).

### Behaviour kept

Card click / Enter opens the modal for items with detail (unchanged code
path). Clicks on Demo/GitHub do not open the modal.

## Part 2 — Voice narration

### Files

`public/audio/<section>-<lang>.mp3`, sections `home, du-an, kinh-nghiem,
lien-he`, langs `vi, en` (8 files, supplied by the owner; ~64 kbps mono).
No placeholder audio is committed.

### Control

- One toggle button (🔇/🔊) in the desktop sidebar and the mobile nav, next to
  the language switcher. `aria-pressed`, label "Bật/Tắt giọng đọc"
  ("Turn voice on/off" in EN). Animated icon while audio is playing.
- Default off. Preference stored in `localStorage['voice'] = 'on' | 'off'`
  (wrapped in try/catch).

### Playback rules

- One shared `Audio` element, `preload="none"`, src set on demand.
- Turning on: play the current section immediately (this click is the user
  gesture that unlocks audio).
- Preference already "on" at load: wait for the first pointerdown/keydown/
  touchstart, then play the current section.
- Section change (desktop: fullpage section becomes `.active`; mobile:
  IntersectionObserver, ≥60% visible): stop current, play the new section's
  file for the current language — only if that section has not been narrated
  yet in this page view.
- Turning off: stop and reset the "already narrated" set.
- Language change: stop; next section change uses the new language.
- `visibilitychange` to hidden: pause; no auto-resume.
- Missing/failed file (`error` event or rejected `play()`): stay silent, no UI
  error.

## Testing (Playwright, desktop + mobile)

- Projects: chip counts match data; filtering shows only matching cards;
  prev/next changes scroll position on desktop; Demo/GitHub have correct
  hrefs and `target=_blank`; cards without detail have no Chi tiết button
  and no detail page; updated visual snapshot of the section.
- Voice (audio requests routed to a tiny generated mp3, `play()` spied):
  off by default → nothing requested; toggle on → `home-<lang>.mp3` played;
  moving to Dự án → `du-an-<lang>.mp3`; missing file → no console error and
  UI unchanged; preference persists across reload.
- Existing suite stays green; `astro check` 0 errors.
